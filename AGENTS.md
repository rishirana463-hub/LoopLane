# Looplane project rules

- Stack: Vite, React, Tailwind CSS, Framer Motion; JavaScript/JSX only.
- Mobile-first, bite-sized learning and instant feedback.
- Keep lessons in `src/data/*.json`, never hardcode lesson content in components.
- Use small reusable components and no unused dependencies.
- Never send or execute learner code on a server; coding exercises run in the isolated browser worker.
- Use original branding and assets; no Duolingo branding, owl, or green brand palette.
- Plan before building. Limit changes to the requested scope and summarize them.
